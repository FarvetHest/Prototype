# SoRR PSP Lite v0.23 — Max

Добавлен играбельный Макс вместо отклонённого прототипа Флойда.
На титульном экране влево/вправо переключают AXEL/MAX; Start или крестик
начинает игру выбранным персонажем. Выбор сохраняется при смерти,
continue и перезапуске L+R. Имя и оригинальный портрет отображаются в HUD.

Макс использует58 готовых пиксельных кадров из локальной SoRR5.2 max.fpg.
Палитра, каждый индекс пикселя и исходные точки опоры сохранены без
перерисовки, масштабирования отдельных кадров или сборки частей тела.
Макс проходит через общий масштаб мира17/14, как остальные персонажи.
Его дополнительный атлас512КиБ хранится в RAM; VRAM1568КиБ и480КиБ
свободного места сохранены. Аксель и противники используют прежний атлас.

Игровая логика Макса пока адаптирована к боевой основе BK3/Lite:
скорость ходьбы/бега80% от Акселя, урон×1,5 с округлением вверх,
более медленные атакующие кадры, увеличенные ударные и уязвимые области.
Сохраняются комбо, прыжки, захваты/броски, спецприёмы, удержание квадрата,
подбор еды и реакции. Это первый тяжёлый профиль Макса, не полный перевод
его оригинального Obj_Max изSoR2. Backbreaker/AtomicDrop и точная физика
оригинальных приёмов ещё не перенесены. Подробности —MAX-RU.md.

Улица SoR1, волны/GO, Barbon, музыка, оригинальные звуки ударов, крики,
мигание тел и шкала спецприёма BK3 сохранены. Маршрут по-прежнему содержит
первый подключённый раунд из8, с очередью20 встреч Lite; исходные очереди,
остальные раунды, боссы и музыка SoR1 пока не подключены.

## Установка

Распакуйте SoRR-PSP-Lite-v0.23-update.zip в корень карты с заменой
PSP/GAME/SORR_LITE/EBOOT.PBP; сохраните прежний music.wav рядом с EBOOT.
Для первой установки используйте полный PSP.zip с музыкой. Исходники,
ресурс max.fpg и воспроизводимый упаковщик находятся в source.zip
и веткеv0.23. HD-прототип Флойда в эти архивы и EBOOT не включён.

## Управление

| Кнопки | Действие |
| --- | --- |
| Крестовина / аналог | Ходьба; после GO идти вправо |
| Дважды влево/вправо, держать второе нажатие | Бег |
| Двойное вверх/вниз | Перекат |
| Квадрат | Подбор рядом с едой; иначе комбо |
| Держать квадрат около0,7с, отпустить на земле | Удар ногой |
| R + квадрат | Удар назад |
| Крестик | Прыжок |
| Квадрат в воздухе | Воздушный удар; с влево/вправо — летящий |
| Вниз + квадрат в воздухе | Стан-атака с группировкой |
| Бег + квадрат | Grand Upper |
| Подойти вплотную | Захват |
| Вперёд + квадрат в переднем захвате | Колени |
| Квадрат без направления в переднем захвате | Удар головой |
| Назад + квадрат в переднем захвате | Передний бросок |
| Квадрат в заднем захвате | Задний бросок |
| Крестик в захвате | Перескок; второй освобождает врага |
| Треугольник / направление + треугольник | Спецприёмы |
| Start | Пауза / подтверждение меню |
| Кружок | FPS / отказ от continue |
| L + R | Новая игра с первой волны |
| L + треугольник | Музыка вкл./выкл. |
| Select | Сохранить lite-profile.csv рядом с EBOOT |

## Проверка на PSP-3000

Выберите MAX на титуле. Проверьте ходьбу, комбо в обе стороны, прыжок,
удержание квадрата и отпускание, два спецприёма, передний/задний захват,
броски, перескок, реакции Zack/Electra и подбор еды квадратом.
Проверьте Max после смерти/continue, затем вернитесь на титул и выберите
AXEL: его скорость/урон должны остаться прежними. Включите FPS кружком;
Select сохраняет lite-profile.csv рядом с EBOOT. Проверьте обычный бой
с4 противниками и бой сBarbon. Новая версия здесь не тестировалась на
физической PSP; результаты PPSSPP —RESULTS.md.

## Сборка

`python build.py --pspdev <путь-к-pspdev>` — установленный PSPSDK.
`python tools/prepare_max.py` — повторная упаковка original/max.fpg:
без сторонних библиотек и без обработки изображения. SHA256 проверяется.
Отчёты, ограничения исходного маршрута и боевой основы:
MAX-RU.md, ROUTE1-RU.md, original/MACHINE-PORT-RU.md, BOSS-RU.md.
Оригинальные код/графика/звук сохраняют авторство правообладателей.

Релизы и архивы: https://github.com/FarvetHest/Prototype/releases

# SoRR PSP Lite v0.11

Нативная PSP-игра на PSPSDK / sceGu, одна арена с четырьмя врагами.
Исправлены спрайты врагов: 48 исходных поз Garcia/Donovan восстановлены
из графики и анимаций BK3 вместо приблизительного выбора FPG. Сохранены
цвета персонажей SoRR; это не обещание совпадения оригинальной палитры CRAM.
Стойка, шаги, удары, боль, удержание, полёт и подъём используют свои кадры,
опорные точки и тайминги60Гц. Из стойки убраны кадры замаха Garcia.
Комбо получило быстрый финал DoubleKick и обычный Kick по таймеру BK3;
таймер серии теперь уменьшается в стойке. Добавлена отдельная реакция Hit2
при ударе удерживаемого врага; исправлен поворот при knockdown.
Пользователь подтвердил30FPS на прежних сборках; v0.11 проверена отдельно.
Полного совпадения всей игры с оригиналом пока нет; ограничения описаны
в PORTING-NOTES.md. На настоящей PSP эта сборка здесь не запускалась.

## Установка

Распакуйте SoRR-PSP-Lite-v0.11-PSP.zip в корень карты памяти.
Получится ms0:/PSP/GAME/SORR_LITE/EBOOT.PBP и music.wav.
Если установлена v0.5.1 или новее, достаточно заменить EBOOT: WAV тот же.
Для старых версий обязательно добавьте music.wav. Нужна поддержка homebrew.
В XMB: SoRR PSP Lite v0.11. CPU 333 МГц, обычный режим памяти MEMSIZE=0.

## Управление

| Кнопки | Действие |
| --- | --- |
| R + квадрат на земле | Удар назад (BackHand) |
| Крестовина / аналог | Ходьба |
| Дважды влево / вправо, держать второе нажатие | Бег |
| Дважды вверх / вниз | Перекат с исходными фазами и скоростью |
| Квадрат | Четырёхчастная цепочка ударов |
| Бег + квадрат | Grand Upper |
| Крестик | Прыжок; квадрат в воздухе — удар |
| Подойти вплотную к стоящему противнику | Захват спереди или сзади |
| Вперёд + квадрат при переднем захвате | Колено; третий приём — колено с подскоком |
| Квадрат без направления при переднем захвате | Завершающий удар головой |
| Назад + квадрат при переднем захвате | Передний бросок |
| Квадрат при заднем захвате | Задний бросок |
| Крестик в захвате | Перескок на другую сторону; первый сохраняет захват, второй освобождает |
| Держать назад в захвате | Отпустить противника после 20 внутренних шагов |
| Треугольник / направление + треугольник | Dragon Wing / Dragon Smash |
| Треугольник в захвате, с любым направлением | Dragon Wing |
| L + треугольник | Музыка вкл./выкл. |
| Start | Пауза игры и музыки |
| Кружок | Показатели FPS и нагрузки |
| L + R | Перезапуск |
| Select | Записать lite-profile.csv рядом с EBOOT |
| HOME | Системный выход с попыткой сохранить профиль |

Передний бросок наносит при ударе о пол 12 HP, задний — 14; летящий враг наносит другим
16 HP один раз за полёт. У полного спецприёма нет расхода здоровья.
При неполной шкале стоимость 14 − (сырой заряд / 8), округление вниз
в делении; здоровье списывается после окончания приёма. При HP ≤ стоимости
приём не начинается. Шкала восстанавливается примерно за пять секунд.

## Проверка на PSP-3000

1. Проверьте стойку/ходьбу обоих врагов, их удары и подъём. Выполните серию быстро и с паузами перед четвёртым ударом — финал должен различаться. Затем R+квадрат с врагом сзади и спереди, затем зеркально при взгляде влево. Проверьте захват при подходе по глубине, захват после обычного удара, спецприём с удерживаемым направлением. Затем оба типа захвата: колени, удар головой, оба броска, перескок.
2. Бросьте врага в другого: HP жертвы списываются при приземлении. Проверьте отскок и подъём, затем повторный захват.
3. Используйте оба спецприёма с полной шкалой, затем до её заполнения.
   Проверьте окончание анимации и однократный расход HP.
4. Проверьте удары врагов и ответ Donovan на прыжок рядом с ним.
5. Несколько минут играйте с музыкой и четырьмя врагами. Кружок включает
   показатели. Цель около 29–30 FPS и LOG без роста D. Select сохранит CSV.

LOG — обновления арены 30 Гц; внутри выполняются два шага контроллеров
по правилам 60 Гц. Ввод считывается 30 раз в секунду. L — среднее время
логики, R — подготовка/завершение GU, D — пропущенные шаги.
Музыка потоковая PCM WAV, 44100 Гц, стерео, 16 бит; занимает 32,8 МиБ
на карте. Два небольших буфера в RAM. Лимит пользователя 1 ГБ не требуется.

## Сборка

    python build.py --pspdev C:/path/to/pspdev

Результат: build/EBOOT.PBP и build/music.wav. Готовые текстуры включены.
Пересоздание данных из своих ресурсов (сначала подготовьте источник BK3,
затем выполняйте в таком порядке):

    python tools/match_enemy_frames.py --asm "C:/path/to/Assemblies/Bare Knuckle 3 (J) [!].asm" --data C:/path/to/SoRR/data
    python tools/extract_bk3.py --asm "C:/path/to/Assemblies/Bare Knuckle 3 (J) [!].asm"
    python tools/extract_physics.py --asm "C:/path/to/Assemblies/Bare Knuckle 3 (J) [!].asm"
    python tools/prepare_enemy_data.py
    python tools/prepare_sprites.py --data C:/path/to/SoRR/data

Прочие инструменты подготовки:


    python tools/prepare_sprites.py --data C:/path/to/SoRR/data
    python tools/extract_bk3.py --asm "C:/path/to/Assemblies/Bare Knuckle 3 (J) [!].asm"
    python tools/extract_physics.py --asm "C:/path/to/Assemblies/Bare Knuckle 3 (J) [!].asm"

Источник закреплён по SHA256 и commit в assets/bk3-reference.json.
Нужный листинг есть в ранее подготовленном SoR-original-code-research.zip.
139 кадров персонажей, три T8-страницы; вместе с фоном, HUD и двумя экранами
занято 1824 КиБ из 2048 КиБ VRAM. FPG во время игры не декодируется.

Тесты: tools/emulator_check.py --pspdev C:/path/to/pspdev --soak-seconds 30.
Нужны websocket-client и PPSSPP с локальным debugger, SoftwareRenderer.
Тест изменяет позиции и HP только у SORL00011. Итоги в RESULTS.md,
машинные отчёты и снимки в test-results/. Авторство SoRR/SEGA и разметки
дизассемблированного кода сохраняется за соответствующими создателями.
